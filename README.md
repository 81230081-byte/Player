# عاداتي - Islamic Habits Pro v2.0

تطبيق تتبع العادات الإسلامية الاحترافي

## الميزات

- ✅ تتبع الصلوات الخمس مع أوقات ديناميكية
- ✅ أذكار الصباح والمساء والنوم مع عداد تفاعلي
- ✅ نظام نقاط XP ومستويات
- ✅ سلسلة الإنجاز (Streak) مع حديقة الأعمال
- ✅ وضع ليلي/نهاري
- ✅ دعم Offline (PWA)
- ✅ تصدير/استيراد البيانات
- ✅ إشعارات ذكية
- ✅ اهتزاز (Haptic Feedback)
- ✅ رسوم متحركة (Confetti)

## البنية المعمارية

```
src/
├── core/           # State, Router, i18n, API
├── components/     # UI Components
├── pages/          # Page Components
├── services/       # Business Logic
├── utils/          # Helpers
└── app.js          # Entry Point
```
