# تطبيق عاداتي — روتينك الإسلامي

## كيفية التثبيت على هاتفك

### للأندرويد (Chrome):
1. افتح الملف `index.html` في متصفح Chrome
2. اضغط على القائمة (ثلاث نقاط) → "Add to Home screen" أو "إضافة إلى الشاشة الرئيسية"
3. سيتم تثبيته كتطبيق حقيقي!

### للآيفون (Safari):
1. افتح الملف في Safari
2. اضغط على زر المشاركة (السهم لأعلى)
3. اختر "Add to Home Screen" أو "إضافة إلى الشاشة الرئيسية"
4. سيتم تثبيته كتطبيق حقيقي!
